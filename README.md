\# ModaStyle — Assistant RAG

\## 1. Présentation
ModaStyle est une boutique fictive spécialisée dans la mode au Maroc.
Ce projet consiste à développer un assistant intelligent basé sur
la technologie RAG (Retrieval-Augmented Generation).
L'assistant répond aux questions des clients en utilisant
les documents de référence de la boutique.

\## 2. Objectifs
\- Répondre aux questions des clients.
\- Rechercher les informations dans les documents.
\- Fournir des réponses accompagnées de sources.
\- Éviter les réponses inventées.
\- Évaluer la qualité du système.

\## 3. Technologies
\- Python 3.12
\- Git
\- Autres technologies à définir.

\## 4. Organisation du projet
\- docs : documentation
\- data : documents du corpus
\- src : code source
\- tests : tests automatiques
\- configs : configurations
\- scripts : scripts d'exécution
\- reports : rapports et résultats
