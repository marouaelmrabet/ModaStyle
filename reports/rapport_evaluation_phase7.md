# Rapport d'évaluation des réponses — Phase 7

## Méthode

Les réponses des configurations A et B ont été évaluées sur trois critères : exactitude, fidélité aux sources et pertinence.
Chaque critère reçoit une note de 0 à 2.
Les moyennes sont calculées sur les 15 questions de chaque configuration.

## Résultats

| Critère | Configuration A | Configuration B |
|---|---:|---:|
| Exactitude | 1.53/2 | 1.87/2 |
| Fidélité aux sources | 1.87/2 | 1.87/2 |
| Pertinence | 1.6/2 | 1.87/2 |

## Score global

- Configuration A : 1.67/2 (83.33 %).
- Configuration B : 1.87/2 (93.33 %).

## Interprétation

Les résultats obtenus avec cette grille donnent un avantage à la configuration B sur le score global.
La configuration A présente toutefois des erreurs notables, notamment une contradiction de prix pour la question Q09 et des refus injustifiés pour Q05 et Q11.
La configuration B répond correctement à davantage de questions, mais certaines formulations contiennent des éléments qui ne sont pas explicitement documentés.

## Limites

- Le jeu d'évaluation contient seulement 15 questions.
- Les notes sont des propositions à vérifier humainement.
- Les critères comportent une part de jugement subjectif.
- Les résultats ne garantissent pas les performances sur toutes les questions possibles.

Les scores doivent être considérés comme préliminaires tant que les annotations n'ont pas été validées.
